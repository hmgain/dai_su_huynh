# Đại Sư Huynh — Art

Ảnh cho bot Discord Đại Sư Huynh. Bot lấy ảnh bằng link raw:
`https://raw.githubusercontent.com/hmgain/dai_su_huynh/main/<game>/<đường dẫn>`

Mỗi game một thư mục riêng:

| Thư mục | Game | Nội dung |
|---|---|---|
| `masoi/` | 🐺 Ma Sói | `roles/<roleId>.png` + `.gif` (thẻ vai), `bg/<tên>.jpg` + `.gif` (ảnh nền) |

Thêm/thay ảnh: giữ đúng tên file, mỗi ảnh có cả bản tĩnh và bản `.gif`.
